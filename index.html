How I got here

None of this was planned. Each stage started because the one before it left me with a question I wanted answered.

  1. 01

    Roblox / Lua

    Lua · Roblox scripting

    Programming started with games. Around age 11 I picked up Lua on Roblox, mostly because I wanted to change how things behaved in games I was already playing. Scripting gameplay and Roblox systems was my first real look at programming logic, and it's what made coding feel interesting instead of theoretical.

  2. 02

    Web

    HTML · CSS · JavaScript

    Lua led me to the browser. I started teaching myself HTML, CSS, and JavaScript in browser-based development environments, learning how a page is structured and how JavaScript changes it. It was my first taste of programming outside of games.

  3. 03

    Blender & 3D

    Blender · 3D modeling · Animation

    I spent a lot of time in Blender learning 3D modeling and animation. It isn't traditional programming, but it showed me how 3D assets get made and how they fit into a game's workflow. That changed how I thought about building games and pushed me further toward game development.

  4. 04

    Unity

    Unity · C#

    Unity was my first larger game engine and my first structured language. Learning C# meant learning how code interacts with game objects, physics, player systems, scenes, and gameplay mechanics.

  5. 05

    Unreal Engine

    Unreal Engine · Blueprints

    From Unity I moved to Unreal Engine and learned Blueprints, game logic, and how level and game systems fit together. I also took an Unreal Engine class through Stanford.

  6. 06

    Cybersecurity

    Linux · Kali Linux · Burp Suite · Nmap · OWASP · OSINT · TryHackMe

    Learning how applications are built made me curious about how they break. I started studying ethical, defensive security through TryHackMe and tools like Kali Linux, Burp Suite, and Nmap, and picked up web security, OWASP concepts, OSINT, networking, and a lot of Linux along the way. It's a field I'm still learning.

  7. 07

    Java & Minecraft

    Java · Paper / Spigot · Gradle

    Java is where things got bigger. Working with Minecraft servers through Paper and Spigot taught me event-driven programming, how to work with APIs, how to find my way around larger codebases, and how to use Gradle and debug server-side systems. It's one of the areas where I've learned the most technically.

  8. 08

    Local AI

    Ollama · Local LLMs · AI-assisted development

    More recently I've been experimenting with running language models locally, trying out coding models, and working AI tools into how I develop. Mostly I've learned where they help, where they don't, and how much the hardware actually matters.

  9. 09

    Three.js

    Three.js · JavaScript · 3D web graphics

    Three.js pulled several earlier stages together: JavaScript from the web, 3D from Blender, and interaction from game development. I'm using it to learn how 3D graphics work in the browser.
